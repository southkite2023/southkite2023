## ACTIVE::PROJECTS

### 🌐 Yuashie Personal Site
**[yuashie.cn](https://yuashie.cn)** · [Repository](https://github.com/southkite2023/Netweb)

A continuously evolving personal platform built with **Vue 3 + Vite** and a **Fastify + PostgreSQL** backend.

Current modules include:

- account system and public profiles
- badges, contribution ledger and community comments
- bug / suggestion feedback workflow
- avatar and administrator tooling
- Minecraft whitelist bridge
- amateur-radio identity, QSO logbook and eQSL system
- multilingual interface and legal / changelog pages

> The goal is not merely to make a homepage, but to build a long-lived personal digital space.

### ⛏ Project 002 · Minecraft

A survival server connected to the Yuashie account system.

The website handles player identity and whitelist requests, while a Paper-side bridge synchronizes the approved whitelist over HTTPS without exposing public RCON access.

### 📻 Project 003 · Yuashie Radio

An amateur-radio module integrated into the personal site.

It supports callsign identity, operator class, QSO logging, QSL templates, in-site eQSL delivery and public station pages.

### 🛰 Personal Automation

Small tools and experiments for information aggregation, workflow automation, data processing and personal knowledge infrastructure.
